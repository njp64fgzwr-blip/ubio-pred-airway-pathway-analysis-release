# Signature provenance metadata

`signature_provenance_no_gene_membership.csv` contains the 39 reader-facing
signature labels, source context, traceability grades and interpretation
limits used to regenerate Supplementary Figure S12. It contains no gene-symbol
membership and no participant data.

The exact frozen 39-signature membership file is not redistributed. An
authorised user must supply it separately, and the pipeline verifies its
SHA-256 checksum before use.
