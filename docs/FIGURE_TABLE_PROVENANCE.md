# Dissertation figure and table provenance

## Authority and release boundary

The scientific visual authority is the dissertation-locked R-generated set
dated 18 August 2026: Figures 1–9 and Supplementary Figures S1–S12. The
repository includes the generating code, complete legends and non-content
checksum inventories, but not the U-BIOPRED-derived figure or result files.

An authorised full run writes those artifacts to the ignored local output
root. The inventories in `validation/reference_manifests/` permit comparison
by logical filename, size and SHA-256 without publishing the files. No figure
should be described as external validation: matched-participant figures show
concordance and predictive figures show internal repeated nested
cross-validation.

## Generating-script chain

- `R/25_generate_final_dissertation_figure_set_correct_numbering.R` exports
  Figures 1–9 and S1–S11 in final dissertation order.
- It rebuilds the R plot objects through `R/12_generate_final_figures.R` and
  `R/14_generate_draft_matched_figures.R`.
- `R/26_validate_final_dissertation_figure_set_correct_numbering.R` checks
  inventory, titles, formats and source lineage.
- `R/27_regenerate_table1_correct_numbering.R` generates main Table 1.
- `R/28_generate_signature_provenance_outputs.R` generates Figure S12 from the
  frozen signature file and the tracked gene-membership-free provenance map.
- `run_outputs.R` orchestrates these stages after the scientific analysis.

## Verification rule

For an authorised rerun:

1. confirm the 13 processed-input hashes and frozen-signature hash;
2. confirm expected datasets, outcomes and model combinations;
3. reconstruct plotted values from their named source tables or matrices;
4. compare titles, axes, panels and the legends in `docs/FIGURE_LEGENDS.md`;
5. compare locked hashes where the software environment permits byte-identical
   export; and
6. distinguish graphics-device or PDF-metadata differences from numerical
   differences.

Never substitute an older or differently designed output merely because its
filename or modification date appears newer.
