# Controlled result outputs

This GitHub repository intentionally does not include dissertation figures,
U-BIOPRED-derived result tables, participant-level files or fitted models.
They remain in the authorised local analysis environment.

The repository does include:

- the complete generating and validation code;
- privacy-safe source and output checksum inventories under
  `validation/reference_manifests/`;
- input schemas; and
- a wholly synthetic end-to-end software demonstration.

An authorised user can recreate controlled outputs beneath the ignored
`work/full_analysis/` directory with `run_analysis.R` and `run_outputs.R`.
Repository-facing figures or result tables should be added only after the
relevant institutional and U-BIOPRED release approval has been recorded.
